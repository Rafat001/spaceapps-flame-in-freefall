# Data provenance

Everything the app answers from is in this tree. Nothing outside the official challenge resources (and the references
they name) is loaded. `sources/official/MANIFEST.md` lists every stored official file with its URL and SHA-256.

| Path | What | Source |
| --- | --- | --- |
| `sources/psi/PSI-*.json` | 24 raw PSI Combustion Science investigation records (19 microgravity, 5 ground / modeling), unchanged API responses | `https://psi.nasa.gov/geode-py/ws/repo/investigations/<ID>`, public, CC0-1.0 per record. Fetch dates in `sources/psi/ACCESSED_AT.txt` |
| `sources/psi/search_research_area_combustion_science.json` | Raw PSI search listing the 24 combustion-science investigations | `https://psi.nasa.gov/geode-py/ws/repo/search?ffield=Research Area&fvalue=combustion science` |
| `sources/psi/search_q_combustion_all_areas.json` | Raw PSI keyword search across all research areas (catalog statistics only) | `https://psi.nasa.gov/geode-py/ws/repo/search?q=combustion&size=200` |
| `sources/psi/experimental_tables/*.csv` | PSI "Experimental table" files, unchanged | Download links issued by PSI (`/geode-py/ws/studies/<ID>/download?file=…`) |
| `sources/psi/analyzed/` | Small PSI "Analyzed Data" files (PSI-117, PSI-142) kept as official documents | Same PSI download links (see the manifest) |
| `sources/official/` | Official challenge resources: NASA fact sheets and Researcher's Guide (PDF + per-page text), NASA web pages (HTML + text), guidance-video metadata and transcript | URLs and SHA-256 in `sources/official/MANIFEST.md`; registry in `apps/api/app/ingest/official_sources.py` |
| `sources/challenge/` | Capture of the challenge Details page (HTML + text) | `https://www.spaceappschallenge.org/2026/challenges/flame-in-freefall/?tab=details` |
| `sources/spaceapps_challenge_details.md` | Challenge brief text the seed builder chunks | Team-pasted copy of the Details tab; provenance in the file header |
| `curation/nasa_program.v1.json` | Map from PSI investigations to verbatim NASA programme excerpts | Hand-made; every excerpt is checked word for word against the stored source at ingest |
| `seed/investigations.v2.json` | Seed `v2`: 24 investigations with 2,009 PSI experimental-table rows, normalised, plus catalog stats (as of 2026-11-13) | Built by `make seed` (`python -m app.ingest.build_seed`, deterministic) |
| `seed/challenge_brief_chunks.v2.json` | 20 paragraph chunks of the official brief | Same builder |
| `db/`, `index/` | SQLite DB with FTS5 table, and FAISS / NumPy vectors | Generated by `make ingest` (git-ignored). The API Docker image builds them at image build time |

Raw PSI zip / ts / mp4 archives (about 13.5 TB) and experiment videos are never downloaded or ingested. File lists
are stored as metadata and the app links out to PSI.

Rules applied by the builder:
- Only columns whose meaning and unit are explicit are normalised (O2 → % by volume, pressure → kPa, flow → m/s);
  every value keeps its verbatim `source_text`, PSI file and row number.
- Ambiguous cells stay **unknown** with a flag, never reinterpreted: e.g. BRE `3400%` / `2100%`
  (`suspicious_percent_format`), FLEX row with `0` mmHg ambient pressure, SPICE negative air rates, `RAMPED`, `n/a`.
- CFI-G inverse-flame `XO2` is the **oxidizer stream from the burner**, not the ambient atmosphere — stored with that context.
- Investigation-level fuel class / family are curator classifications, each justified by a quoted sentence of the official brief.
- Topic and measurement-type tags are rule-based keyword matches on PSI text; each stores the triggering sentence.
- No paper titles, page numbers or URLs were written by hand: publication titles/DOIs are copied from PSI records.
